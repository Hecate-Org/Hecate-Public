### Justification

The public GitHub repository tc4dy/CVE-2026-121529-Toolkit provides a working exploit toolkit for CVE-2026-121529, a critical (CVSS 9.6) origin validation error in FortiClient's FortiPAM privileged session component. The toolkit includes 'Full Exploit (RCE via CORS, browser payload server, interactive shell, mass scan, enum, chain mode, SOCKS5/Tor, stealth)' capabilities, lowering the barrier for exploitation. The vulnerability targets the local API endpoint at hxxp://127[.]0[.]0[.]1:9191/api/v1/privileged/session and WebSocket endpoint ws://127[.]0[.]0[.]1:9191/ws, with the WebSocket endpoint not governed by CORS policies. While Fortinet reports no active exploitation in the wild, the availability of public tooling with mass scanning and stealth features increases the risk of opportunistic attacks against organizations running vulnerable FortiClient versions (7.2.0-7.2.14, 7.4.0-7.4.7). Successful exploitation grants interactive shell access through the privileged session component, enabling post-exploitation activity on affected endpoints.
