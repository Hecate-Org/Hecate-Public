## LEARN: Prepare the Hunt

### Hypothesis Statement

Adversaries exploit CVE-2024-3400 in PAN-OS GlobalProtect gateway using crafted HTTP requests with shell commands in session cookies to achieve unauthenticated remote code execution, could establish cron-based persistence (capability; not observed in the source), and deploy the UPSTYLE backdoor for credential harvesting and data exfiltration

### Threat Context

Source CTI:

> TLP:CLEAR - Palo Alto Networks PAN-OS GlobalProtect Command Injection (CVE-2024-3400)
Adversaries exploit an unauthenticated remote code execution vulnerability in Palo Alto Networks PAN-OS GlobalProtect gateway (CVE-2024-3400).
Threat actors send crafted HTTP requests containing arbitrary command injection sequences within session cookies to /ssl-vpn/hipreport[.]esp.
Upon successful exploitation, the gateway process executes arbitrary shell commands with root privileges (T1059.004) spawning /bin/sh or /bin/bash.
Adversaries establish persistence by writing malicious cron schedules to /etc/cron.d/ (T1053.003) to regularly download secondary payloads.
The attackers deploy the UPSTYLE backdoor to harvest configuration credentials, active session tokens, and system information, exfiltrating data via outbound HTTPS connections (T1071.001) or web-accessible staging paths.
Detection guidance:
1. Web server logs: Inspect requests to /ssl-vpn/hipreport[.]esp containing shell metacharacters (backticks, $(...), semicolons) in Cookie or SESSID headers.
2. Process creation: Detect web gateway processes (pan_comm, nginx, httpd) spawning /bin/sh, curl, or bash to execute commands or write to /etc/cron.d/.
3. File integrity: Detect creation or modification of unexpected files in /etc/cron.d/ or /var/appweb/sslvpndocs/.

### Justification

CVE-2024-3400 is an actively exploited command injection vulnerability in Palo Alto Networks PAN-OS GlobalProtect gateway that allows unauthenticated remote code execution with root privileges. The threat intel describes a complete attack chain from initial exploitation through persistence and data exfiltration, including deployment of the UPSTYLE backdoor. Organizations running affected PAN-OS versions (10.2, 11.0, 11.1) with GlobalProtect gateway or portal are at immediate risk. The vulnerability enables attackers to harvest configuration credentials, active session tokens, and system information, directly threatening VPN infrastructure security and potentially enabling lateral movement (capability; not observed in the source) into protected networks.
