### Justification

CISA has added CVE-2026-102895 to the Known Exploited Vulnerabilities catalog, confirming active in-the-wild exploitation. The vulnerability allows unauthenticated administrative access to GPUStack, potentially enabling attackers to create persistent (capability; not observed in the source) administrator API keys for long-term access, disclose worker and cloud-provider secrets, and execute arbitrary code through the /v2/inference-backends/from-yaml endpoint. Organizations running GPUStack face immediate risk of complete system compromise, credential theft, and code execution without any authentication barrier. The combination of network accessibility, no privilege requirements, and code execution capability makes this a critical threat requiring urgent detection and remediation.
