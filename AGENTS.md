# Hecate Public workspace

Use the installed `hecate-agent` CLI for research, hunt and investigation creation, validation, search, and other supported framework operations. Read `knowledge/environment.md` and `knowledge/hunting-knowledge.md` before proposing hunts.

Use grounded research before AI-generated hypotheses. Use the LOCK pattern (Learn, Observe, Check, Keep), focus on adversary behavior, and label unexecuted queries as unvalidated. Create hunts and investigations with the CLI rather than writing their initial files manually.

This is a public workspace. Keep credentials in the ignored `.env` file. Keep private telemetry, evidence, and customer or organization details out of committed files. Review content before publishing it.
