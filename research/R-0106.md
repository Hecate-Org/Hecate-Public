### Summary
Ivanti Connect Secure acts as an extranet session host to authorize and intermediate access to resources for users. ## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit CVE-2026-118527, a predictable identifier vulnerability in Ivanti Connect Secure, to upload attacker-controlled files to known disk locations. This technique is chained with CVE-2026-104935 and CVE-2026-111357 to achieve unauthenticated root-level code execution without relying on authenticated access.

### Key Findings
- The vulnerability CVE-2026-118527 allows remote authenticated attackers to generate predictable numbers or identifiers, facilitating file uploads with attacker-controlled content to specific disk locations.
- Exploitation of CVE-2026-118527 is part of a chain involving CVE-2026-104935 (CVSS 4.3) and CVE-2026-111357 (CVSS 8.8), resulting in unauthenticated root access.
- Threat actor UTA0576 has been observed leveraging this exploit chain to extract credentials, perform host reconnaissance, and search for administrator passwords and BitLocker recovery keys.
- Affected products include Ivanti Connect Secure versions <= 25.1.1.2 and <= 22.8R2.5, which are currently being actively exploited in the wild.
- CISA has listed CVE-2026-118527 in the Known Exploited Vulnerabilities Catalog with a remediation deadline of November 13, 2026.

## 5. Research Synthesis

### Executive Summary
Active exploitation of CVE-2026-118527 in Ivanti Connect Secure allows authenticated attackers to upload malicious files via predictable identifiers, which are chained with CVE-2026-104935 and CVE-2026-111357 to achieve unauthenticated root code execution. Detection requires correlating anomalous file upload patterns with subsequent system reconnaissance and credential harvesting activities, as the initial vulnerability is a logic flaw rather than a network-based injection.

### Recommended Hypothesis
> Adversaries use predictable file identifiers in Ivanti Connect Secure to upload web shells or payloads to known disk locations to achieve unauthenticated root-level code execution and credential harvesting

### Gaps Identified
- Lack of integrity monitoring on the specific administrative file storage paths (e.g., Core File Generation directories) enables detection blind spots for the initial file upload phase before chain exploitation occurs
