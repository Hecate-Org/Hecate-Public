## 1. System Research: How It Works

### Summary
The target system is a Motorola Moto G Stylus 5G 2023 (genevn) device running a Linux kernel affected by the GhostLock vulnerability (CVE-2026-43499). An attacker can achieve root-level access without flashing or unlocking the bootloader by exploiting this memory corruption flaw in the rtmutex subsystem, typically involving the transfer and execution of a statically linked C binary via ADB.

### Key Findings
- The vulnerability (CVE-2026-43499) is a kernel-level memory corruption issue within the Linux rtmutex subsystem, specifically related to incorrect usage of 'current' instead of 'waiter::task' in remove_waiter(), affecting kernels from version 2.6.39 to 6.19.0.
- Exploitation involves pushing a statically linked C binary named 'ghostlock_static' to the device path '/data/local/tmp/' and executing it, likely requiring an active ADB shell connection rather than a network-facing application vector despite MITRE T1190 tags.
- The PoC is designed to bypass standard security controls by functioning on devices with a locked bootloader and does not require flashing custom firmware or recovery images.
- Secondary OSINT data indicates the vulnerability has a moderate EPSS score (0.89%) and is currently not listed in the VulnCheck KEV, suggesting it is in an early stage of weaponization with limited widespread automated exploitation.

The attack involves deploying static binaries via ADB to temporary storage locations to bypass standard security controls and escalate privileges.

### Key Findings
