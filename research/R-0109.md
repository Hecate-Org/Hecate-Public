## 1. System Research: How It Works

### Summary
The Linux kernel's IPv4 TCP stack handles connection setup by initially creating a request socket (reqsk) that stores IP options, which are then passed to the child socket upon handshake completion without being copied, leading to a use-after-free race condition if the reqsk is freed prematurely. This vulnerability allows unauthenticated remote attackers to trigger denial of service or potential remote code execution by sending crafted SYN packets with specific IP options to any listening TCP port on an affected host.

### Key Findings
- The vulnerability is triggered during standard TCP three-way handshake processing in tcp_v4_syn_recv_sock(), specifically when the kernel passes pointers from the request socket to the new child socket without making a copy of the IP options.
- Exploitation requires sending crafted IPv4 packets containing specific options (such as MPTCP capabilities) to a reachable listening TCP socket, with no authentication required for the initial connection attempt.
- The race condition involves timing the free operation on the request socket against another CPU processing a retransmitted SYN, allowing an attacker to read or corrupt freed memory via the stale pointer in the child socket.
- A secondary exploitation path exists through request-socket migration (tcp_migrate_req), which is only active when specific kernel configurations are enabled, expanding the attack surface beyond the primary unpatched code path.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse CVE-2026-98432, a critical use-after-free race condition in the Linux kernel's IPv4 TCP networking stack, to achieve unauthenticated remote root code execution via TCP SYN packets carrying specific IPv4 options. Although a Proof-of-Concept exploit exists on GitHub for public-facing applications (T1190), reliable exploitation is currently hindered by the narrow timing window and the need for complex heap grooming.

### Key Findings
- The vulnerability (CVE-2026-98432) has a CVSS score of 9.8 and affects major Linux distributions including Ubuntu, RHEL, Debian, and Amazon Linux, though patches have been released upstream and backported to maintained stable branches.
- A functional PoC repository (H1z3-br0/CVE-2026-98432) provides tools for detection and exploitation, including command-line utilities like `cve_2026_98432` with flags such as `--check`, `--probe`, and `--race` to identify and exploit the flaw.
- Successful exploitation requires a Multipath TCP (MPTCP) listener on the target and involves a complex multi-stage process including KASLR bypass, heap grooming, and payload delivery to achieve arbitrary command execution as root.
- The EPSS score for this vulnerability is 0.46% (Moderate/Low), indicating a relatively low probability of exploit in the wild currently, and it is not yet listed in the VulnCheck KEV database.
- Detection capabilities include network-based rules monitoring for TCP SYN packets with specific IPv4 options, as well as process creation indicators for the PoC tool execution and pcap analysis scripts.
