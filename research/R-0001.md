## 1. System Research: How It Works

### Summary
BraZetsu is a Python-based Windows malware framework operating as an Initial Access Broker that converts compromised systems into commercial assets on the 'Infected Marketplace' by harvesting sensitive data like CNAB financial files and browsing histories. The system utilizes Websocket-based Command and Control (C2) channels to execute remote payloads via cmd.exe and employs AI-enhanced reconnaissance to profile victims across corporate, financial, and industrial sectors in Latin America and Iberia.

### Key Findings
- The malware framework uses specific distribution domains such as caixaentradas1inboxshop.site and caixaentradas1boxshop.site to host initial loader files including msdege[0-9].exe and wifi_driver.exe, which serve as entry points for the BraZetsu agent.
- C2 communications are established through WebSocket protocols connecting to c2.installscenter.com and historically to infect.online (IP 38.242.246.176), allowing operators to remotely execute arbitrary shell commands via cmd.exe.
- Data exfiltration capabilities include querying SQLite browser databases using SQL statements like 'SELECT url, title, visit_count FROM urls WHERE url LIKE ?' to cross-reference browsing history against global TARGET_DOMAINS variables for targeted reconnaissance.
- The malware performs system enumeration by reading specific registry keys under SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall and SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall to identify installed applications, while previously utilized the 'MonitorSystem' registry key for persistence.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The BraZetsu malware framework, attributed to the Exilware actor, functions as an Initial Access Broker toolkit that commercializes compromised systems through an 'Infected Marketplace,' leveraging Python-based modules and AI-enhanced reconnaissance to harvest sensitive data. While MITRE T1113 (Screen Capture) is listed in the technique tags, the provided primary source text does not describe specific screen capture mechanisms, instead detailing other intelligence gathering methods like SQLite database queries for browsing history and registry enumeration for installed applications.

### Key Findings
- BraZetsu operates as a comprehensive Initial Access Broker (IAB) framework rather than a standard infostealer, allowing criminals to remotely execute payloads on compromised systems via the 'Infect Marketplace' platform hosted on domains like infect.online and installscenter.com.
- The malware utilizes AI-enhanced reconnaissance capabilities to target corporate, financial, industrial, and law enforcement environments across Iberia and Latin America, with a specific focus on harvesting Brazilian CNAB financial transaction files and digital certificates.
- Intelligence gathering techniques documented in the primary source include querying SQLite databases (e.g., 'SELECT url, title, visit_count FROM urls') to cross-reference browsing history with global target variables, and reading Windows Registry keys under 'SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall' to identify installed applications.
- The framework demonstrates rapid technical evolution since February 2026, progressing from basic remote access tools to a sophisticated platform that compiles Python code using Nuitka for evasion and employs WebSocket-based Command and Control (C2) channels.
- Key indicators of compromise include specific file hashes for loaders like msedge04.exe and wifi_driver.exe, as well as distribution domains such as caixaentradas1inboxshop.site and caixaentradas1boxshop.site, while previous iterations utilized the 'MonitorSystem' registry key for persistence.

The BraZetsu framework, attributed to the Exilware actor, utilizes AI-enhanced reconnaissance and Python-based modular architecture to harvest sensitive financial (CNAB) and browsing data via SQLite queries and registry enumeration. While T1113 is tagged, the primary evidence emphasizes data collection over screen capture, necessitating a hunt focused on the underlying intelligence gathering mechanisms rather than just screenshot artifacts.
